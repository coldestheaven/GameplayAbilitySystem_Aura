## 🐛 故障排除

### 问题 1: 编译错误 - 找不到头文件

**错误信息**:
```
fatal error C1083: Cannot open include file: 'Actor/PoolableObject.h'
```

**解决方案**:
1. 检查文件是否存在于正确路径
2. 重新生成项目文件（右键 .uproject → Generate Visual Studio project files）
3. 清理并重新编译

---

### 问题 2: 对象池子系统为空

**症状**:
```cpp
UObjectPoolSubsystem* PoolSubsystem = GetWorld()->GetSubsystem<UObjectPoolSubsystem>();
// PoolSubsystem == nullptr
```

**解决方案**:
1. 确保 `ObjectPoolSubsystem.h` 中正确声明了 `UCLASS()`
2. 确保继承自 `UWorldSubsystem`
3. 重新编译项目

---

### 问题 3: 投射物不归还到池

**症状**:
- 投射物消失但没有归还日志
- 池中的非活动对象数量不增加

**解决方案**:
1. 检查 `AAuraProjectile::OnSphereOverlap` 中的归还逻辑
2. 确保调用了 `PoolSubsystem->ReleaseActor(this)`
3. 检查 `CanReturnToPool()` 返回值

---

### 问题 4: 性能没有提升

**可能原因**:
1. 池配置不当（InitialSize太小）
2. 对象重置逻辑太重
3. 测试场景不够复杂

**解决方案**:
1. 增加池的初始大小
2. 优化 `OnAcquiredFromPool` 和 `OnReturnedToPool`
3. 使用更复杂的测试场景（更多投射物）
