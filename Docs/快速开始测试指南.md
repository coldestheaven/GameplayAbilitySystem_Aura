## 1️⃣ 对象池系统测试

### 步骤 1: 打开测试关卡

1. 在编辑器中，打开任意测试关卡（或创建新关卡）
2. 推荐使用现有的测试关卡，如果有的话

### 步骤 2: 添加测试Actor

1. 在 **Content Browser** 中搜索 `ObjectPoolTest`
2. 如果没有蓝图版本，我们需要在关卡中直接放置C++类：
   - 在 **Place Actors** 面板中，搜索 `ObjectPoolTest`
   - 或者在 **World Outliner** 右键 → **Place Actor** → 搜索 `ObjectPoolTest`

### 步骤 3: 配置测试参数

在 **Details** 面板中配置：

```
Test Settings:
├─ Test Projectile Class: BP_Projectile (或你的投射物类)
├─ Num Tests: 100 (测试次数)
├─ Test Interval: 0.1 (测试间隔)
└─ Enable Performance Comparison: true (启用性能对比)
```

### 步骤 4: 运行测试

1. 点击 **Play** 按钮运行游戏
2. 测试会自动开始
3. 观察 **Output Log** 中的输出

### 步骤 5: 查看结果

在 **Output Log** 中查找：

```

LogObjectPool: Traditional Spawn Time: 15.234ms
LogObjectPool: Object Pool Time: 6.123ms
LogObjectPool: Performance Improvement: 59.8%
LogObjectPool: Memory Saved: 2.4MB
```

## 2️⃣ 事件总线系统测试

### 步骤 1: 创建测试蓝图

1. 在 **Content Browser** 中右键
2. 选择 **Blueprint Class** → **Actor**
3. 命名为 `BP_EventBusTest`

### 步骤 2: 添加事件订阅

在蓝图的 **Event Graph** 中：

#### 方法 A: 使用C++集成示例（推荐）

1. 在关卡中放置 `EventBusIntegrationExample` Actor
2. 运行游戏，查看日志输出

#### 方法 B: 在蓝图中订阅事件

1. 在 **BeginPlay** 节点后添加：

```
BeginPlay
    ↓
Get Game Instance
    ↓
Get Subsystem (Aura Event Bus)
    ↓
Subscribe to Attribute Changed Event
    ↓
Bind Event (OnAttributeChanged)
```

2. 创建自定义事件 `OnAttributeChanged`：

```
Event OnAttributeChanged
    ↓
Print String: "Attribute Changed!"
    ↓
Print String: Attribute Tag
    ↓
Print String: New Value
```

### 步骤 3: 发布测试事件

创建一个测试按钮或定时器：

```
Event Tick (或按键事件)
    ↓
Get Game Instance
    ↓
Get Subsystem (Aura Event Bus)
    ↓
Publish Attribute Changed Event
    ├─ Attribute Tag: "Attributes.Vital.Health"
    ├─ Old Value: 100.0
    └─ New Value: 80.0
```

### 步骤 4: 运行测试

1. 点击 **Play** 按钮
2. 触发事件（按键或自动）
3. 观察控制台输出

### 步骤 5: 查看结果

在 **Output Log** 中查找：

```
LogAuraEventBus: Event Published: AttributeChanged
LogAuraEventBus: Subscribers Notified: 3
LogAuraEventBus: Event Dispatch Time: 0.05ms
```

在屏幕上看到：

```
Attribute Changed!
Attributes.Vital.Health
80.0
```

## 3️⃣ 配置化技能系统测试

### 步骤 1: 创建技能配置资产

1. 在 **Content Browser** 中右键
2. 选择 **Miscellaneous** → **Data Asset**
3. 选择 `AbilityConfigData` 类
4. 命名为 `DA_FireBall_Config`

### 步骤 2: 配置火球术技能

在 **Details** 面板中配置：

#### 基础信息

```
Ability Name: "火球术"
Ability Description: "发射一个火球，对敌人造成伤害"
Cooldown Duration: 2.0
Mana Cost: 25.0
```

#### 动作配置

**动作 1: 播放施法动画**

```
Action Type: PlayMontage
Delay: 0.0
Montage Asset: [选择施法动画]
Play Rate: 1.0
```

**动作 2: 播放施法音效**

```
Action Type: PlaySound
Delay: 0.0
Sound Asset: [选择施法音效]
Volume: 1.0
Pitch: 1.0
```

**动作 3: 生成火球投射物**

```
Action Type: SpawnProjectile
Delay: 0.5 (等待施法动画)

Projectile Config:
├─ Projectile Class: BP_FireBall
├─ Spawn Location: Caster
├─ Spawn Offset: (100, 0, 50)
├─ Speed: 1000.0
├─ Homing: true
├─ Homing Acceleration: 2000.0
└─ Lifetime: 5.0
```

**动作 4: 播放施法特效**

```
Action Type: SpawnParticle
Delay: 0.5

Particle Config:
├─ Particle System: [选择火球特效]
├─ Spawn Location: Caster
├─ Spawn Offset: (50, 0, 100)
├─ Scale: (1, 1, 1)
└─ Auto Destroy: true
```

### 步骤 3: 创建可配置技能

#### 方法 A: 在蓝图中创建（推荐）

1. 创建新的 **Blueprint Class** → **GameplayAbility**
2. 父类选择 `ConfigurableAbility`
3. 命名为 `GA_FireBall_Configurable`

4. 在 **Class Defaults** 中：
   ```
   Ability Config: DA_FireBall_Config
   ```

#### 方法 B: 直接使用C++类

1. 在技能授予时，使用 `UConfigurableAbility` 类
2. 设置 `AbilityConfig` 属性为 `DA_FireBall_Config`

### 步骤 4: 授予技能

在角色的 **AbilitySystemComponent** 中：

```
BeginPlay
    ↓
Get Ability System Component
    ↓
Give Ability
    ├─ Ability Class: GA_FireBall_Configurable
    └─ Level: 1
```

3. 观察技能效果

## 🐛 常见问题排查

### 问题 1: 对象池测试Actor找不到

**症状**: 在编辑器中搜索不到 `ObjectPoolTest`

**解决方案**:
1. 确认编译成功
2. 重启编辑器
3. 在 **Place Actors** 面板中，勾选 **Show Engine Content** 和 **Show Plugin Content**
4. 搜索 `ObjectPoolTest`

### 问题 2: 事件总线订阅失败

**症状**: 订阅事件后没有收到通知

**解决方案**:
1. 确认 `UAuraEventBus` 子系统已初始化
2. 检查事件类型是否匹配
3. 确认订阅者对象未被销毁
4. 查看日志中的错误信息

### 问题 3: 配置化技能不执行

**症状**: 激活技能后没有任何效果

**解决方案**:
1. 确认 `AbilityConfig` 已设置
2. 检查动作配置是否正确
3. 查看日志中的错误信息
4. 确认资产引用有效

### 问题 4: 投射物不使用对象池

**症状**: 投射物仍然每次创建销毁

**解决方案**:
1. 确认投射物类实现了 `IPoolableObject` 接口
2. 检查 `bUseObjectPool` 标志是否为 true
3. 确认对象池子系统已初始化
4. 查看日志中的池化信息

### 问题 5: 性能没有提升

**症状**: 优化后性能没有明显改善

**解决方案**:
1. 确认测试场景足够复杂（投射物数量 > 50）
2. 使用 Unreal Insights 进行详细分析
3. 检查是否有其他性能瓶颈
4. 对比优化前后的数据

## 📈 性能监控

### 使用 Unreal Insights

1. 启动游戏时添加参数：`-trace=cpu,frame,log`
2. 运行测试场景
3. 在 Unreal Insights 中分析数据

### 关键指标

| 指标 | 监控方法 | 目标值 |
|------|---------|--------|
| **帧率** | stat fps | > 60 FPS |
| **内存** | stat memory | 稳定 |
| **对象池命中率** | 日志 | > 90% |
| **事件延迟** | 日志 | < 0.1ms |
| **技能执行时间** | 日志 | < 100ms |

### 日志命令

在控制台中输入：

```
// 显示帧率
stat fps

// 显示内存使用
stat memory

// 显示对象池统计
log LogObjectPool Verbose

// 显示事件总线统计
log LogAuraEventBus Verbose

// 显示技能系统统计
log LogAbilitySystem Verbose
```
