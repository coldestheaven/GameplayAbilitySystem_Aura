## 🎯 系统概述

### 什么是事件总线？

事件总线是一个**中央事件分发系统**，用于解耦组件间的通信。它允许：
- 发布者发送事件，无需知道谁在监听
- 订阅者接收事件，无需知道谁在发送
- 多个订阅者可以监听同一个事件
- 动态添加/移除订阅者

### 架构图

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  Publisher  │────────>│  Event Bus  │────────>│ Subscriber  │
│   (发布者)   │ Publish │  (事件总线)  │ Notify  │  (订阅者)   │
└─────────────┘         └─────────────┘         └─────────────┘
                              │
                              ├────────>│ Subscriber 2 │
                              │
                              └────────>│ Subscriber 3 │
```

### 解决的问题

#### ❌ 传统方式（紧耦合）
```cpp
// AttributeSet 直接调用 WidgetController
void UAuraAttributeSet::PostGameplayEffectExecute(...)
{
    // 需要获取 WidgetController 引用
    UOverlayWidgetController* Controller = GetWidgetController();
    if (Controller)
    {
        Controller->OnHealthChanged.Broadcast(NewHealth);
    }
}
```

**问题**：
- AttributeSet 需要知道 WidgetController 的存在
- 添加新的监听者需要修改 AttributeSet
- 难以测试和维护

#### ✅ 事件总线方式（解耦）
```cpp
// AttributeSet 只发布事件
void UAuraAttributeSet::PostGameplayEffectExecute(...)
{
    FAttributeChangedEvent Event;
    Event.AttributeTag = HealthTag;
    Event.OldValue = OldHealth;
    Event.NewValue = NewHealth;
    
    EventBus->Publish(Event);
}

// WidgetController 订阅事件
void UOverlayWidgetController::BindCallbacksToDependencies()
{
    EventBus->Subscribe<FAttributeChangedEvent>([this](const FAttributeChangedEvent& Event) {
        if (Event.AttributeTag == HealthTag)
        {
            OnHealthChanged.Broadcast(Event.NewValue);
        }
    });
}
```

**优势**：
- ✅ 完全解耦
- ✅ 易于添加新监听者
- ✅ 易于测试
- ✅ 支持多个订阅者

## 🧩 核心概念

### 1. 事件类型（Event Types）

所有事件必须继承自 `FAuraEvent`：

```cpp
USTRUCT(BlueprintType)
struct FAuraEvent
{
    GENERATED_BODY()
    
    UPROPERTY(BlueprintReadOnly)
    FGameplayTag EventTag;
    
    UPROPERTY(BlueprintReadOnly)
    float Timestamp;
};
```

#### 内置事件类型

| 事件类型 | 说明 | 使用场景 |
|---------|------|---------|
| `FAttributeChangedEvent` | 属性变化 | 生命值、法力值变化 |
| `FAbilityActivatedEvent` | 技能激活 | 技能使用 |
| `FDamageEvent` | 伤害事件 | 造成/受到伤害 |
| `FXPGainedEvent` | 经验获得 | 击杀敌人 |
| `FLevelUpEvent` | 等级提升 | 角色升级 |
| `FCharacterDeathEvent` | 角色死亡 | 角色死亡 |
| `FAbilityEquippedEvent` | 技能装备 | 技能槽变化 |

### 2. 事件总线（Event Bus）

事件总线是一个 `GameInstanceSubsystem`，生命周期与游戏实例相同。

#### 获取事件总线

```cpp
// C++
UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(this);

// 蓝图
EventBus = Get Event Bus (Self)
```

### 3. 订阅（Subscribe）

订阅事件以接收通知：

```cpp
// C++ - Lambda 方式
EventBus->Subscribe<FAttributeChangedEvent>([this](const FAttributeChangedEvent& Event) {
    UE_LOG(LogTemp, Log, TEXT("Health changed: %f"), Event.NewValue);
});

// C++ - 成员函数方式
EventBus->Subscribe<FAttributeChangedEvent>(
    [this](const FAttributeChangedEvent& Event) {
        OnAttributeChanged(Event);
    }
);
```

### 4. 发布（Publish）

发布事件以通知所有订阅者：

```cpp
// C++
FAttributeChangedEvent Event;
Event.AttributeTag = HealthTag;
Event.OldValue = 100.f;
Event.NewValue = 80.f;
Event.Instigator = this;
Event.Timestamp = GetWorld()->GetTimeSeconds();

EventBus->Publish(Event);

// 蓝图
Publish Attribute Changed (Event Bus, Event)
```

## 🚀 快速开始

### 步骤 1: 获取事件总线

```cpp
// 在 BeginPlay 中
void AMyActor::BeginPlay()
{
    Super::BeginPlay();
    
    EventBus = UAuraEventBus::GetEventBus(this);
    if (!EventBus)
    {
        UE_LOG(LogTemp, Error, TEXT("Failed to get EventBus"));
        return;
    }
}
```

### 步骤 2: 订阅事件

```cpp
void AMyActor::SubscribeToEvents()
{
    // 订阅属性变化
    EventBus->Subscribe<FAttributeChangedEvent>(
        [this](const FAttributeChangedEvent& Event) {
            if (Event.AttributeTag.MatchesTag(FGameplayTag::RequestGameplayTag("Attributes.Vital.Health")))
            {
                UpdateHealthBar(Event.NewValue);
            }
        }
    );
    
    // 订阅伤害事件
    EventBus->Subscribe<FDamageEvent>(
        [this](const FDamageEvent& Event) {
            ShowDamageNumber(Event.Damage, Event.bCriticalHit);
        }
    );
}
```

### 步骤 3: 发布事件

```cpp
void AMyCharacter::TakeDamage(float DamageAmount, bool bCrit)
{
    // 应用伤害逻辑...
    
    // 发布伤害事件
    FDamageEvent Event;
    Event.Damage = DamageAmount;
    Event.bCriticalHit = bCrit;
    Event.bBlockedHit = false;
    Event.Attacker = DamageInstigator;
    Event.Victim = this;
    Event.Timestamp = GetWorld()->GetTimeSeconds();
    
    EventBus->Publish(Event);
}
```

## 📚 API 参考

### UAuraEventBus

#### 核心方法

##### Subscribe<TEvent>
```cpp
template<typename TEvent>
FDelegateHandle Subscribe(TFunction<void(const TEvent&)> Handler)
```
**说明**: 订阅事件  
**参数**: 
- `Handler`: 事件处理函数
**返回**: 订阅句柄（用于取消订阅）

**示例**:
```cpp
auto Handle = EventBus->Subscribe<FAttributeChangedEvent>(
    [](const FAttributeChangedEvent& Event) {
        // 处理事件
    }
);
```

##### Publish<TEvent>
```cpp
template<typename TEvent>
void Publish(const TEvent& Event)
```
**说明**: 发布事件  
**参数**: 
- `Event`: 事件数据

**示例**:
```cpp
FAttributeChangedEvent Event;
Event.NewValue = 100.f;
EventBus->Publish(Event);
```

##### GetEventBus (Static)
```cpp
static UAuraEventBus* GetEventBus(const UObject* WorldContextObject)
```
**说明**: 获取事件总线实例  
**参数**: 
- `WorldContextObject`: 世界上下文对象
**返回**: 事件总线实例

**示例**:
```cpp
UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(this);
```

#### 蓝图方法

##### PublishAttributeChanged
```cpp
UFUNCTION(BlueprintCallable)
void PublishAttributeChanged(const FAttributeChangedEvent& Event)
```

##### PublishDamage
```cpp
UFUNCTION(BlueprintCallable)
void PublishDamage(const FDamageEvent& Event)
```

##### GetSubscriptionCount
```cpp

int32 GetSubscriptionCount(FName EventName) const
```

## 🔧 集成指南

### 集成到 AttributeSet

#### 修改前（传统方式）
```cpp
void UAuraAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    // 直接调用委托
    if (Data.EvaluatedData.Attribute == GetHealthAttribute())
    {
        // 需要获取 WidgetController
        // 紧耦合
    }
}
```

#### 修改后（事件总线）
```cpp
void UAuraAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetHealthAttribute())
    {
        float OldHealth = GetHealth();
        SetHealth(FMath::Clamp(GetHealth(), 0.f, GetMaxHealth()));
        float NewHealth = GetHealth();
        
        // 发布事件
        if (UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(GetOwningActor()))
        {
            FAttributeChangedEvent Event;
            Event.AttributeTag = FGameplayTag::RequestGameplayTag("Attributes.Vital.Health");
            Event.OldValue = OldHealth;
            Event.NewValue = NewHealth;
            Event.Instigator = Data.EffectSpec.GetEffectContext().GetInstigator();
            Event.Timestamp = GetWorld()->GetTimeSeconds();
            
            EventBus->Publish(Event);
        }
    }
}
```

### 集成到 WidgetController

#### 修改前
```cpp
void UOverlayWidgetController::BindCallbacksToDependencies()
{
    // 直接绑定到 AttributeSet
    AbilitySystemComponent->GetGameplayAttributeValueChangeDelegate(
        AttributeSet->GetHealthAttribute()
    ).AddLambda([this](const FOnAttributeChangeData& Data) {
        OnHealthChanged.Broadcast(Data.NewValue);
    });
}
```

#### 修改后
```cpp
void UOverlayWidgetController::BindCallbacksToDependencies()
{
    // 通过事件总线订阅
    if (UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(this))
    {
        EventBus->Subscribe<FAttributeChangedEvent>(
            [this](const FAttributeChangedEvent& Event) {
                if (Event.AttributeTag.MatchesTag(FGameplayTag::RequestGameplayTag("Attributes.Vital.Health")))
                {
                    OnHealthChanged.Broadcast(Event.NewValue);
                }
            }
        );
    }
}
```

### 集成到 GameplayAbility

```cpp
void UAuraProjectileSpell::ActivateAbility(...)
{
    Super::ActivateAbility(...);
    
    // 发布技能激活事件
    if (UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(GetAvatarActorFromActorInfo()))
    {
        FAbilityActivatedEvent Event;
        Event.AbilityTag = AbilityTags.First();
        Event.Instigator = GetAvatarActorFromActorInfo();
        Event.Target = nullptr;
        Event.Timestamp = GetWorld()->GetTimeSeconds();
        
        EventBus->Publish(Event);
    }
}
```

## ✨ 最佳实践

### 1. 事件命名规范

```cpp
// ✅ 好的命名
FAttributeChangedEvent
FAbilityActivatedEvent
FCharacterDeathEvent

// ❌ 不好的命名
FEvent1
FMyEvent
FData
```

### 2. 事件数据设计

```cpp
// ✅ 包含足够的上下文信息
USTRUCT(BlueprintType)
struct FDamageEvent : public FAuraEvent
{
    GENERATED_BODY()
    
    UPROPERTY(BlueprintReadOnly)
    float Damage;
    
    UPROPERTY(BlueprintReadOnly)
    bool bCriticalHit;
    
    UPROPERTY(BlueprintReadOnly)
    AActor* Attacker;
    
    UPROPERTY(BlueprintReadOnly)
    AActor* Victim;
};

// ❌ 信息不足
USTRUCT(BlueprintType)
struct FDamageEvent : public FAuraEvent
{
    GENERATED_BODY()
    
    UPROPERTY(BlueprintReadOnly)
    float Damage;  // 缺少上下文
};
```

### 3. 订阅管理

```cpp
// ✅ 保存订阅句柄
class AMyActor : public AActor
{
private:
    TArray<FDelegateHandle> SubscriptionHandles;
    
    void SubscribeToEvents()
    {
        auto Handle = EventBus->Subscribe<FAttributeChangedEvent>(...);
        SubscriptionHandles.Add(Handle);
    }
    
    void EndPlay(const EEndPlayReason::Type EndPlayReason) override
    {
        // 清理订阅
        SubscriptionHandles.Empty();
    }
};
```

### 4. 避免循环依赖

```cpp
// ❌ 不要在事件处理器中发布相同类型的事件
EventBus->Subscribe<FAttributeChangedEvent>([this](const FAttributeChangedEvent& Event) {
    // 这会导致无限循环！
    EventBus->Publish(Event);
});

// ✅ 使用标志位防止循环
bool bIsProcessingEvent = false;

EventBus->Subscribe<FAttributeChangedEvent>([this](const FAttributeChangedEvent& Event) {
    if (bIsProcessingEvent) return;
    
    bIsProcessingEvent = true;
    // 处理逻辑
    bIsProcessingEvent = false;
});
```

### 5. 性能考虑

```cpp
// ✅ 只订阅需要的事件
void SubscribeToHealthEvents()
{
    EventBus->Subscribe<FAttributeChangedEvent>(
        [this](const FAttributeChangedEvent& Event) {
            // 早期过滤
            if (!Event.AttributeTag.MatchesTag(HealthTag))
            {
                return;
            }
            
            // 处理健康变化
            UpdateHealthBar(Event.NewValue);
        }
    );
}

// ❌ 订阅所有事件然后过滤
void SubscribeToAllEvents()
{
    EventBus->Subscribe<FAttributeChangedEvent>(
        [this](const FAttributeChangedEvent& Event) {
            // 处理所有属性变化（性能浪费）
        }
    );
}
```

## ⚡ 性能优化

### 1. 事件过滤

在订阅时进行早期过滤：

```cpp
EventBus->Subscribe<FAttributeChangedEvent>(
    [this](const FAttributeChangedEvent& Event) {
        // 早期返回，避免不必要的处理
        if (Event.Instigator != GetOwner())
        {
            return;
        }
        
        // 处理事件
    }
);
```

### 2. 批量事件

对于频繁触发的事件，考虑批量处理：

```cpp
class UBatchedEventProcessor
{
private:
    TArray<FAttributeChangedEvent> PendingEvents;
    FTimerHandle BatchTimer;
    
    void OnAttributeChanged(const FAttributeChangedEvent& Event)
    {
        PendingEvents.Add(Event);
        
        if (!BatchTimer.IsValid())
        {
            GetWorld()->GetTimerManager().SetTimer(
                BatchTimer,
                this,
                &UBatchedEventProcessor::ProcessBatch,
                0.1f,  // 每 0.1 秒处理一次
                false
            );
        }
    }
    
    void ProcessBatch()
    {
        // 批量处理所有事件
        for (const auto& Event : PendingEvents)
        {
            // 处理...
        }
        PendingEvents.Empty();
        BatchTimer.Invalidate();
    }
};
```

### 3. 条件订阅

只在需要时订阅：

```cpp
void AMyWidget::NativeConstruct()
{
    Super::NativeConstruct();
    
    // 只在 Widget 可见时订阅
    if (IsVisible())
    {
        SubscribeToEvents();
    }
}

void AMyWidget::SetVisibility(ESlateVisibility InVisibility)
{
    Super::SetVisibility(InVisibility);
    
    if (InVisibility == ESlateVisibility::Visible)
    {
        SubscribeToEvents();
    }
    else
    {
        UnsubscribeFromEvents();
    }
}
```

## 🔍 故障排除

### 问题 1: 事件未触发

**症状**: 发布事件后，订阅者没有收到通知

**可能原因**:
1. 事件总线未初始化
2. 订阅在发布之后
3. 事件类型不匹配

**解决方案**:
```cpp
// 1. 检查事件总线
if (!EventBus)
{
    UE_LOG(LogTemp, Error, TEXT("EventBus is null!"));
    return;
}

// 2. 确保订阅在发布之前
void BeginPlay()
{
    Super::BeginPlay();
    SubscribeToEvents();  // 先订阅
}

// 3. 检查事件类型
EventBus->Subscribe<FAttributeChangedEvent>(...);  // 订阅
EventBus->Publish<FAttributeChangedEvent>(...);    // 发布（类型必须匹配）
```

### 问题 2: 内存泄漏

**症状**: 内存持续增长

**可能原因**: 订阅未清理

**解决方案**:
```cpp
void EndPlay(const EEndPlayReason::Type EndPlayReason) override
{
    // 清理所有订阅
    SubscriptionHandles.Empty();
    
    Super::EndPlay(EndPlayReason);
}
```

### 问题 3: 性能下降

**症状**: 帧率下降

**可能原因**: 
1. 事件处理器执行耗时操作
2. 订阅者过多

**解决方案**:
```cpp
// 1. 异步处理耗时操作
EventBus->Subscribe<FDamageEvent>(
    [this](const FDamageEvent& Event) {
        // 使用异步任务
        AsyncTask(ENamedThreads::GameThread, [this, Event]() {
            // 耗时操作
        });
    }
);

// 2. 检查订阅数量
int32 Count = EventBus->GetSubscriptionCount(FName("FAttributeChangedEvent"));
UE_LOG(LogTemp, Warning, TEXT("Subscription count: %d"), Count);
```

## 📊 性能指标

### 预期性能

| 指标 | 值 |
|------|-----|
| 订阅开销 | < 0.01ms |
| 发布开销（10个订阅者） | < 0.1ms |
| 内存开销（每个订阅） | ~100 bytes |
| 最大订阅者数量 | 1000+ |

### 性能测试

```cpp
// 测试代码
void PerformanceTest()
{
    // 测试订阅性能
    double StartTime = FPlatformTime::Seconds();
    for (int32 i = 0; i < 1000; ++i)
    {
        EventBus->Subscribe<FAttributeChangedEvent>([](const FAttributeChangedEvent&) {});
    }
    double SubscribeTime = (FPlatformTime::Seconds() - StartTime) * 1000.0;
    UE_LOG(LogTemp, Log, TEXT("Subscribe 1000 times: %.2f ms"), SubscribeTime);
    
    // 测试发布性能
    FAttributeChangedEvent Event;
    StartTime = FPlatformTime::Seconds();
    for (int32 i = 0; i < 1000; ++i)
    {
        EventBus->Publish(Event);
    }
    double PublishTime = (FPlatformTime::Seconds() - StartTime) * 1000.0;
    UE_LOG(LogTemp, Log, TEXT("Publish 1000 times: %.2f ms"), PublishTime);
}
```
