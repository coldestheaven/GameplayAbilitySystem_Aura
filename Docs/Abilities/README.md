# 技能详细文档索引

本文档目录包含项目中所有技能的详细说明文档。

## 主动技能 (Offensive Abilities)

### 投射物技能

- [FireBolt (火球术)](./FireBolt.md) - 发射追踪火球，造成火焰伤害
- [FireBlast (火球爆炸)](./FireBlast.md) - 向四周发射火球，返回并爆炸
- [ArcaneShards (奥术碎片)](./ArcaneShards.md) - 召唤奥术碎片，造成范围奥术伤害

### 光束技能

- [Electrocute (电击)](./Electrocute.md) - 发射闪电光束，可连锁到多个目标

### 近战技能

- [MeleeAttack (近战攻击)](./MeleeAttack.md) - 近战武器攻击

### 召唤技能

- [SummonAbility (召唤技能)](./SummonAbility.md) - 召唤多个召唤物

## 被动技能 (Passive Abilities)

- [HaloOfProtection (光环保护)](./HaloOfProtection.md) - 提供保护光环效果
- [LifeSiphon (生命汲取)](./LifeSiphon.md) - 从敌人身上汲取生命值
- [ManaSiphon (法力汲取)](./ManaSiphon.md) - 从敌人身上汲取法力值

## 技能分类

### 按伤害类型分类

- **火焰伤害**: FireBolt, FireBlast
- **闪电伤害**: Electrocute
- **奥术伤害**: ArcaneShards
- **物理伤害**: MeleeAttack

### 按技能类型分类

- **投射物技能**: FireBolt, FireBlast, ArcaneShards
- **光束技能**: Electrocute
- **近战技能**: MeleeAttack
- **召唤技能**: SummonAbility
- **被动技能**: HaloOfProtection, LifeSiphon, ManaSiphon

## 技能文档结构

每个技能文档包含以下部分：

1. **技能概述** - 技能的基本信息和特点
2. **技能描述** - 游戏内显示的技能描述
3. **技能参数** - 所有可配置的参数
4. **实现细节** - 技能的具体实现方式
5. **伤害计算** - 伤害如何计算
6. **Debuff 效果** - 技能可能触发的 Debuff
7. **升级效果** - 技能升级后的变化
8. **使用技巧** - 技能的使用建议
9. **配置指南** - 如何在编辑器中配置技能
