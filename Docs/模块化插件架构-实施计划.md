## 🎯 实施目标

### 主要目标

3. **改善团队协作** - 减少代码冲突
4. **支持独立测试** - 每个模块可独立测试

## ⚠️ 注意事项

### 迁移检查清单

每个文件迁移时需要检查：

- [ ] 更新 `#include` 路径
- [ ] 更新 `AURA_API` 为对应插件的API宏
- [ ] 检查依赖关系是否正确
- [ ] 更新前向声明
- [ ] 测试编译
- [ ] 测试运行时功能

### API宏定义

```cpp
// AuraCore 插件
#define AURACORE_API

// AuraGAS 插件
#define AURAGAS_API

// AuraUI 插件
#define AURAUI_API

// 主模块
#define AURA_API
```

### 常见问题

**Q: 循环依赖怎么办？**
A: 使用接口（Interface）或事件总线解耦

**Q: 编译时间没有明显改善？**
A: 检查是否有不必要的依赖，使用前向声明

**Q: 插件加载顺序错误？**
A: 在.uplugin中正确配置LoadingPhase和依赖关系
