## 📦 配置数据结构

### 主要配置类型

#### 1. UAbilityConfigData（技能配置）
```cpp
- AbilityTag: 技能标签
- AbilityName: 技能名称
- AbilityDescription: 技能描述
- Actions: 动作序列
- DamageTypes: 伤害类型映射
- CooldownDuration: 冷却时间
- ManaCost: 法力消耗
- CastVisualEffect: 施法视觉效果
- ImpactVisualEffect: 命中视觉效果
```

#### 2. FAbilityActionConfig（动作配置）
```cpp
- ActionType: 动作类型
- Delay: 延迟时间
- ProjectileConfig: 投射物配置
- EffectConfig: 效果配置
- MontageConfig: 动画配置
- AOEConfig: 范围效果配置
- VisualEffect: 视觉效果配置
```

#### 3. FProjectileConfig（投射物配置）
```cpp
- ProjectileClass: 投射物类
- NumProjectiles: 投射物数量
- SpreadAngle: 扩散角度
- bHomingProjectile: 是否追踪
- SocketTag: 生成位置标签
```

## 🔧 使用方法

### 步骤 1: 创建技能配置数据资产

1. 在内容浏览器中右键
2. 选择 `Miscellaneous` → `Data Asset`
3. 选择 `AbilityConfigData`
4. 命名为 `DA_MyAbility`

### 步骤 2: 配置技能属性

```
AbilityTag: Abilities.Fire.MyFireball
AbilityName: 我的火球术
AbilityDescription: 发射一个强大的火球
CooldownDuration: 5.0
ManaCost: 30.0
```

### 步骤 3: 添加动作

```
Action 1:
  ActionType: SpawnProjectile
  Delay: 0.0
  ProjectileConfig:
    ProjectileClass: BP_FireballProjectile
    NumProjectiles: 1
    SpreadAngle: 0.0
    SocketTag: Weapon
```

### 步骤 4: 创建技能蓝图

1. 创建继承自 `ConfigurableAbility` 的蓝图
2. 设置 `AbilityConfig` 为你创建的数据资产
3. 添加到角色的技能列表

```
└─────────────────────────────────────┘
           ↓ 引用
┌─────────────────────────────────────┐
│     UConfigurableAbility            │
│  (Gameplay Ability - 执行逻辑)       │
│                                     │
│  - ExecuteNextAction()              │
│  - ExecuteSpawnProjectile()         │
│  - ExecuteApplyEffect()             │
└─────────────────────────────────────┘
```

### 关键实现

#### 1. 动作序列执行

```cpp
void UConfigurableAbility::ExecuteNextAction()
{
    if (CurrentActionIndex >= AbilityConfig->Actions.Num())
    {
        EndAbility(...);
        return;
    }
    
    const FAbilityActionConfig& ActionConfig = 
        AbilityConfig->Actions[CurrentActionIndex];
    
    if (ActionConfig.Delay > 0.f)
    {
        // 延迟执行
        SetTimer(...);
    }
    else
    {
        // 立即执行
        ExecuteAction(ActionConfig);
        CurrentActionIndex++;
        ExecuteNextAction();
    }
}
```

#### 2. 投射物生成

```cpp
void UConfigurableAbility::ExecuteSpawnProjectile(...)
{
    // 支持多投射物和扩散
    for (int32 i = 0; i < NumProjectiles; ++i)
    {
        // 计算扩散角度
        float CurrentAngle = -SpreadAngle / 2.f + AngleStep * i;
        
        // 从对象池获取
        AAuraProjectile* Projectile = 
            PoolSubsystem->AcquireActor(...);
        
        // 设置伤害参数
        Projectile->DamageEffectParams = 
            MakeDamageEffectParamsFromClassDefaults();
    }
}
```

#### 3. 视觉效果播放

```cpp
void UConfigurableAbility::PlayVisualEffect(...)
{
    // 播放粒子效果
    if (VisualConfig.ParticleSystem.IsValid())
    {
        UNiagaraFunctionLibrary::SpawnSystemAtLocation(...);
    }
    
    // 播放音效
    if (VisualConfig.Sound.IsValid())
    {
        UGameplayStatics::PlaySoundAtLocation(...);
    }
}
```
