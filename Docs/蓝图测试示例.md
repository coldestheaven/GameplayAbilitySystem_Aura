## 3️⃣ 配置化技能系统 - 蓝图测试

### 步骤 1: 创建技能配置资产

**资产名称**: `DA_TestFireBall`  
**类型**: `AbilityConfigData`

#### 配置内容

```yaml
Ability Name: "测试火球术"
Ability Description: "用于测试的火球技能"
Cooldown Duration: 2.0
Mana Cost: 25.0

Actions:
  - Action 1:
      Type: PlayMontage
      Delay: 0.0
      Montage: [选择施法动画]
      Play Rate: 1.0
      
  - Action 2:
      Type: SpawnProjectile
      Delay: 0.5
      Projectile Class: BP_FireBall
      Speed: 1000.0
      Homing: true
      Homing Acceleration: 2000.0
      
  - Action 3:
      Type: PlaySound
      Delay: 0.0
      Sound: [选择音效]
      Volume: 1.0
      
  - Action 4:
      Type: SpawnParticle
      Delay: 0.5
      Particle System: [选择特效]
      Scale: (1, 1, 1)
```

### 步骤 2: 创建技能蓝图

**蓝图名称**: `GA_TestFireBall`  
**父类**: `ConfigurableAbility`

#### Class Defaults 设置

```
Ability Config: DA_TestFireBall
```

### 步骤 3: 创建测试Actor

**蓝图名称**: `BP_AbilityTest`  
**父类**: `Character` (或任何有ASC的Actor)

#### Event BeginPlay - 授予技能

```
┌─────────────────┐
│  Event BeginPlay │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Get Ability System Component  │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Give Ability                   │
│  Ability Class: GA_TestFireBall │
│  Level: 1                       │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Print String                   │
│  "Ability Granted"              │
└─────────────────────────────────┘
```

#### Input Action - 激活技能

```
┌─────────────────┐
│  Input Action   │
│  (例如: 鼠标左键) │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Get Ability System Component  │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Try Activate Ability By Class  │
│  Ability Class: GA_TestFireBall │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│  Branch (Success?)              │
└────┬────────────────────┬───────┘
     │ True               │ False
     ▼                    ▼
┌─────────────────┐  ┌──────────────────┐
│  Print String   │  │  Print String    │
│  "Activated"    │  │  "Failed"        │
└─────────────────┘  └──────────────────┘
```

### 使用方法

1. 创建配置资产 `DA_TestFireBall`
2. 配置技能参数和动作
3. 创建技能蓝图 `GA_TestFireBall`
4. 创建测试Actor `BP_AbilityTest`
5. 放置到关卡中
6. 运行游戏
7. 按键激活技能

## 🎯 完整测试场景

### 创建综合测试关卡

**关卡名称**: `TestLevel_Optimization`

#### 关卡内容

```
TestLevel_Optimization
├─ BP_ObjectPoolTest (对象池测试)
│  └─ Location: (0, 0, 100)
│
├─ BP_EventBusTest (事件总线测试)
│  └─ Location: (500, 0, 100)
│
├─ BP_AbilityTest (技能系统测试)
│  └─ Location: (1000, 0, 100)
│
├─ PlayerStart
│  └─ Location: (0, -500, 100)
│
└─ 测试目标 (敌人或假人)
   └─ Location: (1000, 500, 100)
```

### 测试流程

1. **启动关卡**
   - 打开 `TestLevel_Optimization`
   - 点击 Play

2. **测试对象池**
   - 观察 `BP_ObjectPoolTest` 的日志输出
   - 验证投射物生成和回收

3. **测试事件总线**
   - 按键触发 `BP_EventBusTest` 的事件发布
   - 观察控制台输出

4. **测试技能系统**
   - 控制 `BP_AbilityTest` 角色
   - 按键激活技能
   - 观察技能效果

## 🔧 调试技巧

### 1. 启用详细日志

在 **Project Settings** → **Engine** → **General Settings** 中：

```
Log Categories:
├─ LogObjectPool: Verbose
├─ LogAuraEventBus: Verbose
└─ LogAbilitySystem: Verbose
```

### 2. 使用断点

在蓝图中设置断点：
- 右键节点 → **Add Breakpoint**
- 运行游戏时会在断点处暂停
- 检查变量值

### 3. 使用Print String

在关键位置添加 Print String 节点：
```
Print String
├─ In String: "Debug Info"
├─ Print to Screen: true
├─ Print to Log: true
├─ Text Color: Yellow
└─ Duration: 5.0
```

### 4. 使用Visual Logger

在代码中添加：
```cpp
UE_VLOG(this, LogTemp, Log, TEXT("Debug Message"));
```

在编辑器中：
- **Window** → **Developer Tools** → **Visual Logger**
- 运行游戏并查看日志
