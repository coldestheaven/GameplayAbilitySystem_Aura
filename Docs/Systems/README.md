## 系统分类

### 核心系统

- **属性系统**: 管理所有游戏属性，包括主属性、次属性、抗性等
- **伤害计算系统**: 处理所有伤害计算逻辑
- **Debuff 系统**: 管理持续伤害和状态效果

### 交互系统

- **UI 系统**: MVVM 架构的 UI 实现
- **输入系统**: Enhanced Input 集成和技能输入绑定
