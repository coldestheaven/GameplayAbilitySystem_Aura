## 🎓 使用示例

### 示例 1: 在 AttributeSet 中发布事件

```cpp
void UAuraAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetHealthAttribute())
    {
        float OldHealth = GetHealth();
        SetHealth(FMath::Clamp(GetHealth(), 0.f, GetMaxHealth()));
        float NewHealth = GetHealth();
        
        // 发布属性变化事件
        if (UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(GetOwningActor()))
        {
            FAttributeChangedEvent Event;
            Event.AttributeTag = FGameplayTag::RequestGameplayTag("Attributes.Vital.Health");
            Event.OldValue = OldHealth;
            Event.NewValue = NewHealth;
            Event.Instigator = Data.EffectSpec.GetEffectContext().GetInstigator();
            Event.Timestamp = GetWorld()->GetTimeSeconds();
            
            EventBus->Publish(Event);
        }
    }
}
```

### 示例 2: 在 WidgetController 中订阅事件

```cpp
void UOverlayWidgetController::BindCallbacksToDependencies()
{
    // 通过事件总线订阅
    if (UAuraEventBus* EventBus = UAuraEventBus::GetEventBus(this))
    {
        EventBus->Subscribe<FAttributeChangedEvent>(
            [this](const FAttributeChangedEvent& Event) {
                if (Event.AttributeTag.MatchesTag(FGameplayTag::RequestGameplayTag("Attributes.Vital.Health")))
                {
                    OnHealthChanged.Broadcast(Event.NewValue);
                }
            }
        );
    }
}
```

## 🔍 技术细节

### 架构设计

```
┌─────────────────────────────────────┐
│     UAuraEventBus                   │
│  (GameInstanceSubsystem)            │
│                                     │
│  - TMap<FName, TArray<Handler>>    │
│  - Subscribe<T>()                   │
│  - Publish<T>()                     │
└─────────────────────────────────────┘
           ↑                ↑
           │                │
    ┌──────┴────┐    ┌─────┴──────┐
    │ Publisher │    │ Subscriber │
    └───────────┘    └────────────┘
```

### 关键实现

#### 1. 类型安全的模板方法

```cpp
template<typename TEvent>
int32 Subscribe(TFunction<void(const TEvent&)> Handler)
{
    static_assert(TIsDerivedFrom<TEvent, FAuraEvent>::Value, 
                  "TEvent must derive from FAuraEvent");
    
    const FName EventName = TEvent::StaticStruct()->GetFName();
    
    // 存储类型擦除的处理器
    TFunction<void(const void*)> Wrapper = [Handler](const void* Data) {
        Handler(*static_cast<const TEvent*>(Data));
    };
    
    EventHandlers[EventName].Add(Wrapper);
    return EventHandlers[EventName].Num() - 1;
}
```

#### 2. 高效的事件分发

```cpp
template<typename TEvent>
void Publish(const TEvent& Event)
{
    const FName EventName = TEvent::StaticStruct()->GetFName();
    
    if (EventHandlers.Contains(EventName))
    {
        for (auto& Handler : EventHandlers[EventName])
        {
            Handler(&Event);  // 直接调用，无虚函数开销
        }
    }
}
```

#### 3. 生命周期管理

```cpp
// 自动初始化（GameInstanceSubsystem）
void UAuraEventBus::Initialize(FSubsystemCollectionBase& Collection)
{
    Super::Initialize(Collection);
    UE_LOG(LogTemp, Log, TEXT("[EventBus] Initialized"));
}

// 自动清理
void UAuraEventBus::Deinitialize()
{
    ClearAllSubscriptions();
    Super::Deinitialize();
}
```

## 📝 已知问题和限制

### 当前限制

1. **订阅句柄管理**
   - 当前使用简化的索引作为句柄
   - 不支持精确的取消订阅
   - **解决方案**: 在生产环境中实现完整的句柄管理

2. **蓝图订阅**
   - 当前只支持C++订阅
   - 蓝图只能发布事件
   - **解决方案**: 添加蓝图订阅支持（使用动态委托）

3. **事件优先级**
   - 当前按订阅顺序执行
   - 不支持优先级控制
   - **解决方案**: 添加优先级参数
